# Ghost Puncher — Support

Need help with Ghost Puncher? You're in the right place.

## Common issues

**The game won't launch / crashes on open.**
Restart your iPhone, then try again. If it still crashes, delete the app
and reinstall from the App Store. Your level progress is stored on-device
and will reset.

**Haptics feel weak or missing.**
Open iOS **Settings** → **Sounds & Haptics** → make sure **System
Haptics** is on. Ghost Puncher uses Apple's Core Haptics engine, which
requires this setting.

**The 120Hz "smoothness" isn't kicking in.**
Only available on iPhones with ProMotion displays (iPhone 13 Pro and
newer). On non-ProMotion devices the game runs at 60Hz, which is also
fine.

**The Devil's head looks weird / clips off the top.**
Should be fixed in v2.0 build 1. If you're still seeing this on the
latest version, file an issue.

**Bosses feel too hard.**
That's the design — read the tells. Each boss has a unique movekit:

- **Ghost** (Round 1): vanishes and strikes from the dark, lights-out
  scares. Watch the eye-flash and arm-load.
- **Witch** (Round 2): feints heavily — yellow flash means a fake, no
  damage. Punish her recovery.
- **Devil** (Round 3): slow, heavy hits with phase 2 at half-health.
- **Hidden boss**: three phases. Tells halve in phase 3. Good luck.

## How to report a bug

Open an issue at
[github.com/gangstaapps/ghostpuncher/issues](https://github.com/gangstaapps/ghostpuncher/issues)

Please include:

- iPhone model
- iOS version
- What you were doing when the bug happened
- (Optional) Screenshot or short screen recording
